# Yawmi Local — يومي المحلي

مخطّط يوم يعمل **على جهازك فقط**: لا سيرفر، لا Firebase، لا حساب، ولا اتصال بالإنترنت. مناسب لأي شخص يريد تنظيم يومه.
A private day planner that runs **only on your PC** — no server, no account, no network. · Ein privater Tagesplaner, der **nur auf deinem PC** läuft.

## المزايا / Features / Funktionen

- جدول لكل يوم: أنشطة (تركيز · شخصي · حركة) واستراحات، مع إعادة الترتيب وتحديث المواعيد تلقائيًا.
- مؤقّت مع إيقاف مؤقت و«+٥ دقائق» ومنبّه صوتي يستمر حتى تضغط إيقاف، وإشعار Windows.
- أنشطة مفتوحة بلا مدة (يُحسب وقتها الفعلي).
- ملخّص اليوم: وقت الأنشطة، وقت الراحة، المنجز، التقدّم.
- **ثلاث لغات**: العربية (RTL) · English · Deutsch — تُغيَّر من أعلى الشاشة وتُحفظ، وأول تشغيل يتبع لغة Windows.
- وضع فاتح/داكن، اختصارات لوحة المفاتيح، نسخ احتياطي واستيراد (JSON).
- يقرأ النسخ الاحتياطية القديمة من تطبيق «يومي» الأصلي (نفس الصيغة).

## أين تُحفظ البيانات؟

`%APPDATA%\YawmiLocal` — مجلد مستقل تمامًا، لا يلمس بيانات تطبيق «يومي» القديم (`%APPDATA%\Yawmi`).
لنقل خطتك القديمة: في التطبيق القديم **نسخة احتياطية**، ثم في الجديد **استيراد**.

## الخصوصية

- لا يوجد أي كود اتصال بالشبكة؛ كل الطلبات غير المحلية تُلغى داخل Electron، والـ CSP يمنع `connect-src`.
- الواجهة معزولة (contextIsolation + sandbox)، والموارد تُخدم من بروتوكول محلي `yawmi://app` بقائمة ملفات مسموحة.

## التشغيل والبناء

```powershell
npm install --ignore-scripts
node node_modules/electron/install.js
npm run check
npm test
npm start            # تشغيل للتجربة
npm run build:win    # ينتج release/YawmiLocal-Portable-*.exe و YawmiLocal-Setup-*.exe
```

## هيكل المشروع

- `electron/` — العملية الرئيسية (الحفظ، القوائم، النسخ الاحتياطي، الإشعارات).
- `dist/locales.js` — **كل النصوص بالثلاث لغات** (مصدر واحد للواجهة والقوائم). لإضافة لغة أضف كائنًا جديدًا و`meta` وستظهر في المبدّل.
- `dist/style.css` — التصميم (توكنز، RTL/LTR بخصائص منطقية، فاتح/داكن، متجاوب).
- `tests/` — اختبارات الحفظ، الجدولة، وتطابق مفاتيح اللغات.

الخط العربي: Noto Sans Arabic (SIL OFL) مضمّن في `dist/fonts`.
