# يومي — Yawmi Desktop

تطبيق Windows مستقل لتنظيم الأنشطة والبريكات. يعمل دون إنترنت باستخدام Electron وChromium المدمجين، دون متصفح خارجي أو سيرفر محلي.

## التشغيل

- `Yawmi-Portable-2.1.0-x64.exe`: تشغيل مباشر دون تثبيت. احتفظ بالملف في مكان ثابت وافتحه بدبل كليك.
- `Yawmi-Setup-2.1.0-x64.exe`: معالج تثبيت لحساب المستخدم الحالي، مع اختيار المجلد واختصار سطح المكتب وقائمة Start. لا يحتاج صلاحيات مسؤول.
- النسختان مخصصتان لـ Windows بمعمارية x64، وتشتركان في نفس مجلد البيانات.
- لا تحتاج إلى تثبيت Node.js أو Chrome أو Edge.
- الملفات غير موقعة بشهادة Authenticode؛ لا تتضمن هذه النسخة تحديثًا تلقائيًا.

## الاستخدام

اضغط **أضف نشاط**، واكتب الاسم والمدة والنوع. يمكنك إضافة بريك تلقائي بعد النشاط، أو إضافة بريك مستقل. استخدم الأسهم لتغيير الترتيب؛ المواعيد التالية تتغير تلقائيًا. اضغط زر الاختيار بجوار النشاط ليظهر في المؤقت، ثم ابدأه. يمكنك التوقف مؤقتًا، زيادة خمس دقائق، أو إتمام النشاط.

لكل تاريخ خطة منفصلة. الإعدادات تتحكم في بداية اليوم ومدة البريك الافتراضية. الزر **جرّب خطة بسيطة** يضيف بيانات توضيحية عند خلو اليوم.

### المنبّه الصوتي

عند انتهاء النشاط أو البريك يظهر تنبيه **الوقت خلص!** ويستمر صوت المنبّه في التكرار حتى تضغط **إيقاف المنبّه**. لا يغلقه الضغط على الخلفية أو Escape. يمكنك تجربة الصوت من **إعدادات اليوم ← جرّب صوت المنبّه**. الصوت محلي ومضمّن في البرنامج، ويعمل أثناء التصغير طالما التطبيق مفتوح وصوت Windows غير مكتوم. عند انتهاء المؤقت يستعيد يومي نافذته إذا كانت مصغرة. إغلاق البرنامج يوقف الصوت.

المؤقت يستمر أثناء تصغير النافذة، ويتعامل مع رجوع الجهاز من وضع النوم. يلزم إبقاء البرنامج مفتوحًا للتنبيه. إذا أغلقت البرنامج والمؤقت يعمل، يُحسب الوقت المنقضي عند إعادة فتحه؛ لا يصل تنبيه أثناء الإغلاق. إعدادات عدم الإزعاج في Windows قد تخفي إشعار النظام، ويظل إشعار الواجهة والصوت متاحين.

## الحفظ والنسخ الاحتياطية

- الحفظ الدائم في `%APPDATA%\Yawmi\plan.json`.
- آخر نسخة سابقة في `plan.json.previous`، وحجم النافذة في `window.json`.
- ملفات Chromium الخاصة بالتطبيق في `%APPDATA%\Yawmi\Chromium`؛ لا يقرأ التطبيق ملفات المتصفح الخارجي.
- **نسخة احتياطية** تفتح نافذة حفظ Windows وتصدّر خطة JSON كاملة.
- **استيراد** يفتح نافذة اختيار ملف، ويتحقق من بياناته ثم يطلب تأكيد الاستبدال. يحفظ الخطة الحالية باسم `before-import-*.json` قبل الاستيراد. المؤقت المستورد يصل في وضع التوقف.
- إزالة التثبيت لا تحذف بياناتك. بيانات نسخة HTML القديمة موجودة في متصفحها ولا تنتقل تلقائيًا إلى التطبيق.

## البناء من المصدر

متطلبات التطوير: Windows x64، Node.js 22 أو أحدث وnpm. يلزم الإنترنت لتنزيل الاعتماديات أثناء البناء فقط.

```powershell
npm ci --ignore-scripts
node node_modules/electron/install.js
npm run check
npm test
npm start
npm run build:win
```

ينتج البناء النسخة المحمولة والمثبّت في `release/`. لبناء مجلد التطبيق فقط: `npm run build:dir`.

الخط والأيقونات مضمنة في المشروع. يشمل خط Noto Sans Arabic ترخيص SIL Open Font License في `dist/fonts/OFL.txt`. تشمل حزم Electron تراخيص Electron وChromium الخاصة بها.

## حدود الأمان

الـ renderer منفصل عن الـ main، مع `contextIsolation: true` و`nodeIntegration: false` و`sandbox: true`. الـ preload يتيح عمليات محددة فقط، والتحقق من مرسل IPC ومن مخطط بيانات النسخ الاحتياطية يتم في العملية الرئيسية. الموارد محلية على بروتوكول `yawmi://app` بقائمة ملفات مسموحة. سياسة CSP تمنع السكربتات الخارجية والـ inline scripts والاتصال الشبكي والـ iframes، وتسمح بالأنماط المضمنة لتحديث تقدم المؤقت. الروابط غير المتوقعة والنوافذ الجديدة والتنزيلات وطلبات الصلاحيات ممنوعة. حزمة الإنتاج تقفل fuses تشغيل Node وفحصه وتتحقق من ASAR.

هذا ليس عزلًا كاملًا على مستوى نظام تشغيل Windows. المستخدم وبرامج الجهاز التي لها صلاحية ملفات حسابه يمكنها الوصول لملفات التطبيق وبياناته المحلية.
